# FLUME — web demo

Web demo for **FLUME** (Fast Localized Urban Microclimate Emulator). Pick a city, a height,
a wind direction and a speed, and FLUME predicts the wind field around the buildings. It
runs entirely in your browser on your own GPU (WebGPU); no data leaves your machine.

**Live demo: https://flume.cityffd.ai** (use desktop Chrome or Edge).

**Paper:** *Fast localized urban microclimate emulator: wind and temperatures in unseen urban
morphologies*, Shaoxiang Qin, Theodore Potsis, Dongxue Zhan, Xue Liu, Ted Stathopoulos,
Liangzhu Leon Wang. [arXiv:2503.19708](https://arxiv.org/abs/2503.19708)
